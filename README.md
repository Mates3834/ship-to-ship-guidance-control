# Integrated Path Planning, Guidance, Adaptive Control and State Estimation

An integrated **Guidance, Navigation and Control (GNC)** research framework combining path planning, trajectory generation, guidance, feedback control, adaptive control, and state estimation within a nonlinear 6-DoF simulation environment.

The project investigates the interaction between these subsystems as a complete closed-loop autonomous guidance and control architecture rather than treating planning, control, and estimation as independent problems.

> **Note:** The source code provided in this repository contains generic and sanitized implementations of the main algorithms used in the research framework. System-specific parameters, operational configurations, and implementation details are intentionally omitted.

---

## Overview

The framework combines the following methods:

- A* path planning
- Smooth trajectory generation
- Line-of-Sight (LOS) guidance
- Nonlinear 6-DoF dynamic modeling
- Linear Quadratic Regulator (LQR)
- Linear Quadratic Integral (LQI) control
- Modified Model Reference Adaptive Control (MRAC)
- Luenberger state observation
- Kalman filtering
- Scenario-based performance evaluation

The main objective is to study how planning, guidance, control, and estimation interact within a unified closed-loop architecture.

## 1. Path Planning

A grid-based **A*** search algorithm is used to generate a collision-free path between an initial position and a specified goal.

The A* evaluation function is

```text
f(n) = g(n) + h(n)
```

where:

- `g(n)` is the accumulated path cost,
- `h(n)` is the heuristic estimate of the remaining cost,
- `f(n)` is the total estimated cost.

A Euclidean-distance heuristic can be used to guide the search toward the goal.

The implementation included in this repository demonstrates a generic two-dimensional grid-based A* planner with obstacle avoidance.

---

## 2. Trajectory Generation

The discrete waypoints generated by the path planner are not necessarily suitable for direct dynamic tracking.

A trajectory-generation stage is therefore introduced between planning and guidance.

The research framework investigates smooth trajectory generation to reduce abrupt changes between successive path segments and provide a more trackable reference.

The public implementation includes a generic quintic polynomial trajectory primitive satisfying position, velocity, and acceleration boundary conditions.

A normalized quintic interpolation is defined using

```text
s(τ) = 10τ³ - 15τ⁴ + 6τ⁵
```

with

```text
τ = t / T
```

which provides zero velocity and acceleration at the beginning and end of the segment.

The research framework additionally investigates higher-order trajectory refinement approaches, while the public code intentionally provides a simplified generic implementation.

---

## 3. Line-of-Sight Guidance

A **Line-of-Sight (LOS)** guidance layer converts geometric path information into reference commands for the control system.

For planar waypoint guidance, the desired heading can be represented as

```text
ψ_ref = atan2(y_wp - y, x_wp - x)
```

where:

- `(x, y)` is the current vehicle position,
- `(x_wp, y_wp)` is the active waypoint,
- `ψ_ref` is the desired heading.

A waypoint acceptance radius is used to determine when the current waypoint has been reached.

Conceptually:

```text
Current Position
       +
Target Waypoint
       │
       ▼
   LOS Geometry
       │
       ▼
Heading Reference
       │
       ▼
    Controller
```

## 4. Dynamic Model

The research framework uses a nonlinear **six-degree-of-freedom (6-DoF)** dynamic representation.

A general vehicle state can contain:

```text
Position
x, y, z

Linear Velocity
u, v, w

Attitude
φ, θ, ψ

Angular Rates
p, q, r
```

This allows translational and rotational motion to be represented within the same simulation architecture.

For public demonstration and controller-design purposes, simplified state-space examples are provided instead of system-specific dynamic parameters.

---

## 5. LQR Control

The **Linear Quadratic Regulator (LQR)** provides an optimal state-feedback baseline.

For the linear state-space model

```text
x_dot = Ax + Bu
```

the control law is

```text
u = -Kx
```

where `K` is obtained by minimizing

```text
J = ∫ (xᵀQx + uᵀRu) dt
```

The weighting matrices `Q` and `R` determine the relative importance of state regulation and control effort.

The repository contains a generic MATLAB implementation for calculating the LQR feedback gain from user-defined state-space matrices.

---

## 6. LQI Control

The **Linear Quadratic Integral (LQI)** controller extends the LQR formulation by introducing integral action.

For a tracked output

```text
y = Cx
```

an integral state is introduced:

```text
ξ_dot = r - y
```

The augmented system can then be represented as

```text
[x_dot]   [ A    0 ][x]   [B]u
[ξ_dot] = [-C    0 ][ξ] + [0]
```

and the resulting feedback law includes both state and integral feedback.

The integral component improves reference tracking and helps reduce steady-state error.

---

## 7. Modified Model Reference Adaptive Control

A **Model Reference Adaptive Control (MRAC)** approach is investigated as the adaptive-control component of the framework.

The central idea is to define a reference model representing the desired response and adapt controller parameters according to the difference between the plant response and reference-model response.

```text
Reference ─────► Reference Model ─────┐
     │                                │
     ▼                                ▼
Adaptive Controller ─► Plant ─────► Tracking Error
        ▲                              │
        └──── Adaptation Mechanism ◄───┘
```

A robustness modification can be introduced into the adaptation law to limit parameter drift.

The public repository contains a simplified first-order educational MRAC example demonstrating:

- reference-model tracking,
- adaptive parameter updates,
- control generation,
- sigma modification.

It is intended to illustrate the adaptive-control principle without exposing system-specific controller parameters.

---

## 8. Luenberger Observer

A **Luenberger Observer** is used for model-based state reconstruction.

For

```text
x_dot = Ax + Bu
y = Cx
```

the observer can be written as

```text
x_hat_dot = A x_hat + Bu + L(y - C x_hat)
```

where:

- `x_hat` is the estimated state,
- `L` is the observer gain,
- `y - Cx_hat` is the innovation term.

The observer gain is selected by assigning appropriate observer poles.

The generic MATLAB implementation included in the repository calculates the observer gain using pole placement.

---

## 9. Kalman Filter

A **Kalman Filter** provides recursive state estimation in the presence of process and measurement uncertainty.

For a discrete system

```text
x(k+1) = A x(k) + B u(k) + w(k)

y(k) = C x(k) + v(k)
```

the algorithm alternates between two main stages:

```text
Prediction
    │
    ▼
Predicted State
    │
    ▼
Measurement Update
    │
    ▼
Corrected Estimate
```

The filter combines:

- model-based prediction,
- measurement information,
- process-noise covariance `Q`,
- measurement-noise covariance `R`.

The repository contains a generic discrete Kalman predict/update implementation.

---

## 10. State Estimation Architecture

The Luenberger Observer and Kalman Filter illustrate two complementary estimation approaches.

The **Luenberger Observer** demonstrates deterministic model-based state reconstruction, while the **Kalman Filter** explicitly accounts for stochastic process and measurement uncertainty.

Their role within the overall architecture can be represented as:

```text
Measurements
     │
     ▼
State Estimation
     │
     ▼
Estimated States
     │
     ├────────► Guidance
     │
     └────────► Control
```

This allows the closed-loop architecture to operate using estimated information instead of assuming ideal access to every system state.

## 11. Integrated Closed-Loop Framework

The primary emphasis of the project is **system-level integration**.

```text
Planning
   ↓
Trajectory Generation
   ↓
Guidance
   ↓
Control
   ↓
Vehicle Dynamics
   ↓
State Estimation
   │
   └──────────────► Feedback
```

The framework enables the interaction between different GNC components to be evaluated under common simulation conditions.

Rather than proposing each individual algorithm as a new method, the project focuses on integrating established planning, guidance, control, and estimation techniques into a unified architecture.
